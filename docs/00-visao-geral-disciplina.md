# Visão Geral da Disciplina

## Identificação

- **Disciplina:** Desenvolvimento Web Frontend
- **Carga horária total:** 60h
- **Organização:** 80 aulas de 45 minutos, distribuídas em 40 encontros de 1,5h
- **Periodicidade de referência:** 2 encontros por semana
- **Unidades formativas:** 2 unidades de 30h
- **Público:** Curso Superior de Tecnologia em Sistemas para Internet
- **Instituição:** IFRN — Campus Currais Novos
- **Professor:** Luciano Alexandre de Farias Silva
- **Sala virtual:** a informar pela turma

## Contextualização

Desenvolvimento Web Frontend dá continuidade à disciplina de Padrões Web. O estudante deixa de trabalhar predominantemente com páginas estáticas e passa a organizar interfaces como aplicações compostas por componentes, dados, eventos, rotas e serviços.

Os conhecimentos anteriores não são descartados. HTML semântico, CSS, responsividade, acessibilidade e Git permanecem como base. Tailwind CSS introduz uma abordagem utility-first e Angular estrutura a aplicação, sem substituir a necessidade de compreender a plataforma Web.

## Ementa

Revisão de HTML5 semântico, CSS moderno, responsividade, acessibilidade e versionamento. Desenvolvimento de interfaces com Tailwind CSS, utilitários responsivos, estados, temas e componentes visuais. JavaScript moderno e fundamentos de TypeScript. Arquitetura de aplicações frontend com Angular: componentes, templates, bindings, control flow, comunicação entre componentes, serviços, injeção de dependência, roteamento, formulários reativos, consumo de APIs, RxJS e signals. Testes, qualidade, acessibilidade, build, publicação e projeto final.

## Objetivo Geral

Projetar e desenvolver aplicações frontend modernas, responsivas, acessíveis, componentizadas e integradas a serviços HTTP, aplicando Tailwind CSS, TypeScript e Angular em um fluxo profissional de desenvolvimento.

## Objetivos Específicos

1. Revisar e consolidar os fundamentos adquiridos em Padrões Web.
2. Construir interfaces responsivas por meio da abordagem utility-first.
3. Modelar temas e componentes visuais reutilizáveis com Tailwind CSS.
4. Utilizar JavaScript moderno e TypeScript com tipagem explícita.
5. Decompor interfaces em componentes Angular com responsabilidades claras.
6. Implementar navegação, formulários, serviços e integração com APIs.
7. Trabalhar com fluxos assíncronos e estado reativo.
8. Aplicar testes, acessibilidade, responsividade e critérios de qualidade.
9. Versionar, documentar, publicar e apresentar uma aplicação frontend.

## Competências e Habilidades

Ao final da disciplina, espera-se que o estudante seja capaz de:

- avaliar e refatorar páginas construídas com HTML e CSS;
- traduzir uma referência visual em layout responsivo;
- selecionar utilitários Tailwind sem comprometer semântica e legibilidade;
- definir tokens e padrões visuais consistentes;
- modelar dados e contratos com TypeScript;
- criar e compor componentes Angular;
- implementar comunicação entre componentes e serviços injetáveis;
- configurar rotas e parâmetros de navegação;
- construir formulários reativos com validação e feedback acessível;
- consumir APIs REST com contratos tipados;
- representar carregamento, vazio, sucesso e erro;
- escrever testes de componentes e serviços;
- preparar build de produção e validar uma publicação;
- comunicar decisões técnicas usando evidências.

## Programa

### Unidade 1 — Revisão, Tailwind CSS e TypeScript

- diagnóstico e revisão de HTML semântico, CSS, acessibilidade e Git;
- fundamentos da abordagem utility-first;
- instalação e fluxo de build do Tailwind CSS;
- cores, tipografia, espaçamento, tamanho, bordas e sombras;
- Flexbox, Grid e responsividade mobile-first;
- estados interativos, dark mode e preferências de movimento;
- tema, tokens de design e componentes visuais;
- formulários, tabelas e auditoria de interfaces;
- JavaScript moderno para interfaces;
- TypeScript: tipos, interfaces, unions, generics e narrowing;
- preparação do ambiente Angular.

### Unidade 2 — Angular e Projeto Final

- workspace e Angular CLI;
- componentes standalone e templates;
- bindings, eventos e control flow;
- inputs, outputs e composição;
- serviços e injeção de dependência;
- roteamento e parâmetros;
- formulários reativos;
- HttpClient e APIs REST;
- RxJS e fluxos assíncronos;
- signals e estado derivado;
- integração entre Angular e Tailwind CSS;
- testes, acessibilidade e qualidade;
- planejamento, implementação e publicação do projeto final.

## Metodologia

- aulas expositivas dialogadas e demonstrações ao vivo;
- práticas guiadas com evolução incremental do código;
- exercícios individuais e em dupla;
- leitura orientada de documentação oficial;
- depuração com DevTools, compilador e ferramentas do framework;
- correção coletiva e revisão por pares;
- aprendizagem baseada em projeto;
- registro do processo por commits e documentação técnica.

## Recursos Necessários

- computador com acesso ao terminal;
- editor de código, preferencialmente VS Code ou equivalente;
- navegador moderno e DevTools;
- Node.js em versão compatível com o Angular adotado na turma;
- npm e Angular CLI;
- Git e conta no GitHub;
- acesso às documentações oficiais de Tailwind CSS, TypeScript e Angular;
- plataforma de publicação compatível com aplicações Angular.

- atendimento aos requisitos funcionais;

- semântica, acessibilidade e responsividade;
- uso adequado de TypeScript e da arquitetura Angular;

- autoria e participação no processo.

## Frequência e Acompanhamento

A disciplina prepara o estudante para conteúdos posteriores de arquitetura frontend, integração frontend/backend, aplicações full-stack, testes automatizados, experiência do usuário e desenvolvimento de sistemas para produção.
