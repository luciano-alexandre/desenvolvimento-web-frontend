# Encontros da Disciplina

Esta pasta reúne os roteiros dos 40 encontros de Desenvolvimento Web Frontend. Cada roteiro contém visão geral, conceitos, exemplo, demonstração, prática, exercício, critérios, referências, checklist e questões de fixação.

## Como Usar os Roteiros

Antes do encontro:

- consulte os objetivos e conceitos essenciais;
- confira os pré-requisitos e ferramentas necessárias;
- prepare o projeto ou branch da atividade.

Durante o encontro:

- execute os exemplos em pequenas etapas;
- registre dúvidas e mensagens de erro;
- adapte os exemplos em vez de apenas copiá-los;
- faça commits correspondentes a avanços reais.

Após o encontro:

- conclua a prática e o exercício aplicado;
- percorra o checklist de compreensão;
- responda às questões sem consultar o gabarito oculto;
- prepare a continuidade indicada pelo cronograma.
