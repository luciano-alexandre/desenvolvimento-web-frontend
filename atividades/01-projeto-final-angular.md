# Projeto Final — Aplicação Angular com Tailwind CSS

## Finalidade

O projeto final consolida as competências da disciplina em uma aplicação frontend que resolva um problema claro para um público definido. A entrega deve combinar Angular, TypeScript, Tailwind CSS, integração de dados, testes, acessibilidade, versionamento e publicação.

## Organização

- **Planejamento:** Encontros 33 e 34.
- **Acompanhamento orientado:** Encontros 35 e 36 — uma semana.
- **Apresentações:** Encontros 37 a 40 — duas semanas.

O Projeto Final corresponde a 100% da nota da Unidade 2. A solução deve estar funcional e publicada antes do encontro de apresentação do respectivo grupo.

## Requisitos Obrigatórios

Cada projeto deverá:

1. identificar problema, público e objetivo;
2. manter backlog com histórias e critérios de aceite;
3. usar repositório Git com histórico coerente;
4. possuir README com instruções de instalação, execução, teste e build;
5. utilizar Angular com componentes standalone;
6. possuir pelo menos três rotas, incluindo detalhe ou edição;
7. decompor a interface em componentes reutilizáveis;
8. utilizar TypeScript sem recorrer indiscriminadamente a `any`;
9. implementar serviço injetável;
10. consumir uma API REST ou fonte de dados equivalente aprovada;
11. apresentar estados de carregamento, vazio, erro e sucesso;
12. implementar formulário reativo com validação e mensagens acessíveis;
13. utilizar Tailwind CSS com tema e decisões visuais próprias;
14. ser responsivo em celular, tablet e tela ampla;
15. permitir uso por teclado com foco visível;
16. possuir testes relevantes de componente e serviço;
17. gerar build de produção sem erros;
18. estar publicado em URL acessível para avaliação.

## Critérios de Autoria

Bibliotecas, exemplos, imagens e códigos externos devem ser identificados. O estudante precisa compreender e explicar o que entregar. A avaliação considera o processo registrado, as decisões demonstradas e a capacidade de modificar a solução, não apenas a aparência final.
